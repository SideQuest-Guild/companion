# Asset provenance

Every binary asset in `assets/` is generated from a source already in this guild's repos; this
file is the exact command that produced it, run from the `companion/` repo root unless noted,
so any asset can be regenerated byte-for-byte (or close enough) from source.

Commands assume `../addon` is the `SideQuest-Guild/addon` checkout next to this one, and that
ImageMagick (`magick`) is installed (`brew install imagemagick`). `sips` and `iconutil` ship with
macOS.

## Fonts (`assets/fonts/`)

Copied verbatim from the addon, which already vendors the upstream OFL releases:

```sh
cp ../addon/SideQuest/Media/Fonts/LibertinusSerifDisplay.ttf assets/fonts/
cp ../addon/SideQuest/Media/Fonts/EBGaramond.ttf assets/fonts/
cp ../addon/SideQuest/Media/Fonts/EBGaramond-Italic.ttf assets/fonts/
cp ../addon/SideQuest/Media/Fonts/OFL.txt assets/fonts/
```

## App icon (`assets/icon.png`, `assets/icon.ico`, `assets/icon.icns`)

Source is the guild crest, `../addon/SideQuest/Media/Skin/CrestPortrait.tga` (128x128, RGBA).
`icon.png` is that crest converted to PNG and upscaled to 1024x1024 (the crest has no larger
source; the upscale is soft at full size, which is expected for a 128px source):

```sh
sips -s format png ../addon/SideQuest/Media/Skin/CrestPortrait.tga --out /tmp/crest.png
sips -z 1024 1024 /tmp/crest.png --out assets/icon.png
```

Windows `.ico` (multi-resolution, 16 through 256px) from the same 1024px PNG:

```sh
magick assets/icon.png -define icon:auto-resize=256,128,64,48,32,16 assets/icon.ico
```

macOS `.icns` via an iconset (`iconutil` needs the `.iconset` directory naming convention):

```sh
rm -rf /tmp/icon.iconset && mkdir /tmp/icon.iconset
for size in 16 32 128 256 512; do
  sips -z $size $size assets/icon.png --out /tmp/icon.iconset/icon_${size}x${size}.png
  double=$((size * 2))
  sips -z $double $double assets/icon.png --out /tmp/icon.iconset/icon_${size}x${size}@2x.png
done
iconutil -c icns /tmp/icon.iconset -o assets/icon.icns
```

`packaging/macos/bundle.sh` copies `assets/icon.icns` into the `.app` bundle if present (warns
and ships without an icon otherwise); re-run the `.icns` step above after any `icon.png` change
and before `make bundle-macos`.

## Tray icons (`assets/tray.png`, `assets/tray-template.png`)

Drawn directly with ImageMagick from the same SVG-style paths as the citadel's other drawn marks
(`citadel.css`'s diamond/chevron glyphs): a shield outline with the guild's four-point star
centred in it, in a 44-unit box. Both paths are rendered at 8x (352px) and downsampled to the
target size for clean anti-aliasing, saved as 32-bit RGBA PNG (`PNG32:`):

```sh
SHIELD='M8,6 L36,6 L36,22 C36,31 30,36 22,40 C14,36 8,31 8,22 Z'
STAR='M22,12 C22.8,18 24,19.2 30,20 C24,20.8 22.8,22 22,28 C21.2,22 20,20.8 14,20 C20,19.2 21.2,18 22,12 Z'

# tray.png (Windows/Linux, colour, 64x64): royal shield fill, gold edge, gold star.
magick -size 352x352 xc:none -fill '#22386a' -stroke '#d8ab5c' -strokewidth 8 \
  -draw "path '$SHIELD'" -fill '#d8ab5c' -stroke none -draw "path '$STAR'" \
  -resize 64x64 PNG32:assets/tray.png

# tray-template.png (macOS, 44x44): solid black+alpha template, so AppKit tints the whole icon
# to match the menu bar (light/dark/accent) itself; alpha is the shield-and-star silhouette.
magick -size 352x352 xc:none -fill black -draw "path '$SHIELD'" -draw "path '$STAR'" \
  -resize 44x44 PNG32:assets/tray-template.png
```

## Theme (`assets/theme/sidequest.json`)

Hand-written `gpui-kit` `ThemeConfig`, not generated from another asset; keep its colours in sync
with `src/ui/theme.rs`'s `palette` module and `../addon/DESIGN.md` / `../website/DESIGN.md` by
hand when the brand palette changes.

## Overview room painting (`assets/rooms/courier-loft.webp`)

"The Courier's Loft", generated with Codex image generation from the prompt in
`SideQuest-Guild/.github`'s `art/companion.txt`, style reference
`website/assets/rooms/war-room.webp`. Source is
`../github/art/companion.png` (1698x926); resized to 1600px wide like the other rooms:

```sh
magick ../github/art/companion.png -resize 1600x assets/rooms/courier-loft.webp
```

`war-room.webp` is no longer used by the companion (the Overview room uses this painting
instead) and has been dropped from `assets/rooms/`.

## Rooms and plates (`assets/rooms/`, `assets/plates/`)

Source is the website's painted art, `../website/website/assets/{rooms,plates}/`. Rooms are
already WebP (GPUI's `image` crate decodes WebP natively); downsized to 1600px wide, the window's
room head never needs more. The gate painting and plaque are re-encoded to WebP for size; the
crest keeps its alpha channel as PNG.

```sh
WEB=../website/website/assets
for room in war-room ledger-chamber armory raid-hall round-table; do
  magick "$WEB/rooms/$room.webp" -resize 1600x "assets/rooms/$room.webp"
done
magick "$WEB/plates/hero-art.png" -resize 1600x -quality 88 assets/plates/hero-art.webp
magick "$WEB/plates/cta-plate.png" -resize 700x assets/plates/cta-plate.webp
magick "$WEB/plates/nav-crest.png" -resize x192 assets/plates/nav-crest.png
```

Total added weight is about 1.3 MB. The app icon and tray icons are unchanged (`nav-crest.png`'s
735x1056 aspect isn't square and would need an art-directed crop, not a resize, to serve as an
icon source).
